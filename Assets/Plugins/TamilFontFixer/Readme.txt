To get started:

Add the Tamil Text Fixer component to your TMP_Text components, such as TextMeshProUGUI or TextMeshPro - Text. That's it! It will automatically fix the text.

If you don't want to add the Tamil Text Fixer component to each TextMeshPro object manually, try the experimental feature under Tools > Tamil Font Fixer Settings. It can automatically add the component for you, helping prevent issues if you forget to attach it.

For more integration details, see Docs/Tamil Font Fixer v1.0.0.pdf.
